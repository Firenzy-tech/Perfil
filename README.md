# Portafolio profesional

Página personal responsive en español para presentar un perfil de desarrollo de software.

## Tecnologías
- HTML semántico
- CSS responsive
- JavaScript vanilla
- Sin dependencias ni proceso de compilación

## Ejecutar localmente
Abre `index.html` en tu navegador. También puedes abrir la carpeta en Visual Studio Code y utilizar una extensión de servidor local si quieres recarga automática; no es obligatorio.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño responsive y estilos.
- `script.js`: navegación móvil.
- `assets/`: carpeta opcional para imágenes propias.

## Antes de publicar
1. Añade el nombre profesional que quieres mostrar.
2. Incorpora enlaces reales de LinkedIn, GitHub y contacto.
3. Añade únicamente proyectos con repositorios o demostraciones públicas.
4. Revisa la descripción para que represente fielmente tu experiencia.
5. Si quieres evitar solicitudes externas, puedes retirar la importación de Google Fonts en `styles.css`; hay fuentes de respaldo.

No se han añadido enlaces personales ficticios ni proyectos de ejemplo presentados como reales.

## Publicar con GitHub Pages
1. Crea un repositorio para el sitio en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md`.
3. Abre Settings → Pages.
4. Configura la publicación desde la rama principal y la carpeta raíz.
5. Espera a que GitHub indique la URL publicada y copia esa URL en LinkedIn.
